## Install

1. Download `IslandBar-<version>.zip` and unzip it.
2. Move `IslandBar.app` to `/Applications`.
3. This build is **not notarized**. The first time, macOS will refuse to open it. Go to
   System Settings › Privacy & Security and click **Open Anyway**.

Requires macOS 14 or later. Universal: Apple Silicon and Intel.

Verify the download with the `.sha256` file:
`shasum -a 256 -c IslandBar-<version>.zip.sha256`
